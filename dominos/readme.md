## 📌 Project Overview

The Domino’s Clone is a **static web page** designed using pure HTML.  
It replicates the basic layout and content flow of the Domino’s website without using CSS or JavaScript.

This project helped me understand:
- HTML page structure
- Semantic HTML tags
- Proper use of headings, links, images, and sections
